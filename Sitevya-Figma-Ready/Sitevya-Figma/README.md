# Sitévya — Figma Make Design Pack

Version réduite et autonome créée à partir de la dernière archive Sitévya. Elle est volontairement limitée à quelques fichiers pour faciliter l'import dans Figma Make.

Objectif : servir de base visuelle pour une refonte premium/3D. Le backend, Neon, Better Auth, Discord et Resend restent dans le projet original et seront réintégrés ensuite avec Bolt.

Le prototype contient : Hero 3D, cartes de services, section Web × Discord, animations CSS, responsive et identité Sitévya.
